## Manter os dois idiomas atualizados

Atualize os dois arquivos do par ao mudar a documentação mantida, preserve os links recíprocos de idioma e confira os links locais antes de publicar. Registros históricos devem receber notas quando forem substituídos, em vez de serem reescritos como se descrevessem a implementação de hoje. A tradução não renomeia arquivos-fonte, identificadores de API, valores do banco ou literais de fixtures.
