# OkamiUNI 0.6.8 — Reconnect from the account page

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.6.8/docs/releases/v0.6.8.pt-BR.md) · **English**

Released October 22, 2026. App version **0.6.8**, build **23**.

## What's new

- **Reconnect on the account page.** When a sign-in is refused, **Reconnect** is the button in the header. A Google account opens Google for that mailbox and keeps the local account and its mail. An IMAP account opens the password form, with the address and server already filled in. **Sync now** stays beside it and only retries the sign-in you already have.
- **The message matches the account.** A Google or Microsoft account no longer tells you to check a password when the sign-in was refused. The line says the authorization is no longer valid, and the overview says the address needs to sign in again. An IMAP account still asks you to check the password.

## Installation

If you are on 0.5.6 or newer, the app updates itself. For a fresh install, download **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)** and drag **OkamiUNI** to **Applications**.
