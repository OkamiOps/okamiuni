# OkamiUNI 0.5.9 — Instalador de verdade

**Português (Brasil)** · [English](https://github.com/OkamiOps/okamiuni/blob/v0.5.9/docs/releases/v0.5.9.md)

Lançado em 14 de outubro de 2026. Versão do app **0.5.9**, build **14**.

## Novidades

- **Instalador (.dmg).** Cada release agora traz o `OkamiUNI.dmg`, assinado com Developer ID e notarizado pela Apple. Ao abrir, aparecem o app, uma seta e a pasta Aplicativos: arraste o OkamiUNI para Aplicativos e pronto.
- **Mover para Aplicativos.** Se o OkamiUNI for aberto direto da janela do instalador, ou de Downloads sem ser movido, ele se oferece para ir para Aplicativos e reabre de lá. A atualização automática só funciona de uma pasta gravável como Aplicativos.

## Instalação

Baixe o **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)**, abra e arraste o **OkamiUNI** para **Aplicativos**. Quem está na 0.5.6 ou mais nova recebe esta versão dentro do app.

O `OkamiUNI-0.5.9.zip` é o pacote usado pela atualização automática.
