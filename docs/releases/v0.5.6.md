# OkamiUNI 0.5.6 — Automatic updates

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.5.6/docs/releases/v0.5.6.pt-BR.md) · **English**

Released October 13, 2026. App version **0.5.6**, build **11**.

## What's new

- **Automatic updates (Sparkle 2).** OkamiUNI checks for new versions at launch and every 6 hours and downloads them in the background. When an update is ready, a small button appears in the sidebar with what changed: **Install and relaunch** updates on the spot; otherwise it is installed the next time you quit the app.
- **Silent mode.** Settings → General → Updates → "Install silently when quitting": no button, the update is installed on quit and the next launch shows once what changed.
- **Check for Updates…** in the app menu; Settings shows the current version and a **Check now** button.
- **Signed and notarized.** This is the first release distributed as an app: signed with Developer ID and notarized by Apple, so it opens on any Mac without Gatekeeper blocking it. Every update package is also signed with OkamiUNI's own EdDSA key and is never installed if the signature does not match.

## Installing

Download `OkamiUNI-0.5.6.zip` below, unzip it and move **OkamiUNI** to Applications. From this version on, updates arrive inside the app.
