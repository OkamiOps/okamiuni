# OkamiUNI 0.5.9 — A proper installer

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.5.9/docs/releases/v0.5.9.pt-BR.md) · **English**

Released October 14, 2026. App version **0.5.9**, build **14**.

## What's new

- **Installer (.dmg).** Each release now includes `OkamiUNI.dmg`, signed with Developer ID and notarized by Apple. Opening it shows the app, an arrow and the Applications folder: drag OkamiUNI onto Applications and you're done.
- **Move to Applications.** If OkamiUNI is opened straight from the installer window, or from Downloads without moving it, it offers to move itself to Applications and reopens from there. Automatic updates only work from a writable folder like Applications.

## Installation

Download **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)**, open it and drag **OkamiUNI** onto **Applications**. If you're on 0.5.6 or later, this version arrives inside the app.

`OkamiUNI-0.5.9.zip` is the package used by automatic updates.
