# OkamiUNI 0.5.8 — Updates in plain sight

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.5.8/docs/releases/v0.5.8.pt-BR.md) · **English**

Released October 14, 2026. App version **0.5.8**, build **13**.

## What's new

- **New-version strip in the sidebar.** When an update is ready, a strip with "New version", the version number and an **Install** button appears above "Accounts and providers". Clicking it opens what changed and **Install and reopen**.
- **Update icon always visible.** With nothing new, the icon sits at the end of the "Accounts and providers" row; one click checks right away.
- **Install button in Settings.** In General → Updates, a ready update gets an **Install X and reopen** button, with "What changed" next to it.

## Installation

If you're on 0.5.6 or 0.5.7, this version arrives inside the app. For a fresh install, download `OkamiUNI-0.5.8.zip` below, unzip it and move **OkamiUNI** to Applications.
