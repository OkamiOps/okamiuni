# OkamiUNI 0.6.2 — Updates in plain sight

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.6.2/docs/releases/v0.6.2.pt-BR.md) · **English**

Released October 15, 2026. App version **0.6.2**, build **17**.

## Fixes

- **Check for updates is always at hand.** The ↓ icon sits in the rail above ✦ and shows the installed version and a "Check now" button. When a new version is ready, it gets a dot. Before, it only appeared once a version was ready.
- **Updates in Overview.** In Settings, the Updates row moved from Appearance to Overview, the first page.

## Installation

If you're on 0.5.6 or later, this version arrives inside the app. For a fresh install, download **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)** and drag **OkamiUNI** onto **Applications**.
