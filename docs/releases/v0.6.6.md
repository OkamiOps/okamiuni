# OkamiUNI 0.6.6 — The account password

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.6.6/docs/releases/v0.6.6.pt-BR.md) · **English**

Released October 22, 2026. App version **0.6.6**, build **21**.

## What's new

- **The password is the account password.** Adding a mailbox no longer asks for an app password. The "What is this?" link and the error that told you to create one are gone.
- **The server comes from the domain.** Type the address and OkamiUNI looks up the mail server. A custom domain on Zoho is filled in as `imappro.zoho.com`; Google Workspace as `imap.gmail.com`. You can still edit the server.
- **A refused login is retried, then explained.** The app tries the nearby servers — Zoho's `imap` and `imappro`, the other regions, `mail.yourdomain` — and, if none accept the password, shows the sentence the server sent back. A password with an accent, or a server that refuses the plain login command, is sent with the other method.
- **Sign in with Google** and **Sign in with Zoho** appear next to the form when the address belongs to them. The password form stays on the screen either way. A Zoho address does not also offer Google.
- **Sending follows the same server.** A custom domain on Zoho reads from `imappro` and sends through `smtppro`.

## Installation

If you are on 0.5.6 or newer, the app updates itself. For a fresh install, download **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)** and drag **OkamiUNI** to **Applications**.
