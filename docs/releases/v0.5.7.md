# OkamiUNI 0.5.7 — Update icon in the sidebar

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.5.7/docs/releases/v0.5.7.pt-BR.md) · **English**

Released October 13, 2026. App version **0.5.7**, build **12**.

## What's new

- **Update icon always visible.** It sits in the sidebar footer, next to "Accounts and providers". When a new version is ready it gets an orange dot and opens what changed, with **Install and relaunch**. Otherwise one click checks right away and shows the current version.

## Installation

If you're on 0.5.6, this version arrives inside the app. For a fresh install, download `OkamiUNI-0.5.7.zip` below, unzip it and move **OkamiUNI** to Applications.
