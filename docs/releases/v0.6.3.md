# OkamiUNI 0.6.3 — Calendars

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.6.3/docs/releases/v0.6.3.pt-BR.md) · **English**

Released October 15, 2026. App version **0.6.3**, build **18**.

## New

- **Calendars tab in Settings.** Choose which calendars show in the Calendar, which calendar new events go to and which meeting room is picked by default.
- **Automatic Google Meet.** When you create an event in a Google account, Meet makes a new room for that event with your own account. Nothing to set up.

## Fixes

- **No client ID or secret.** The old calendar integrations screen asked for technical details nobody should have to fill in. It is gone; only rooms that work with one click are shown.

## Installation

If you're on 0.5.6 or later, this version arrives inside the app. For a fresh install, download **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)** and drag **OkamiUNI** onto **Applications**.
