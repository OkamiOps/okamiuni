# OkamiUNI 0.6.9 — Ask the email

[Português (Brasil)](https://github.com/OkamiOps/okamiuni/blob/v0.6.9/docs/releases/v0.6.9.pt-BR.md) · **English**

Released October 22, 2026. App version **0.6.9**, build **24**.

## What's new

- **The AI menu is in the reader.** **✦ AI** opens it under the toolbar. **Summarize**, **Draft a reply** and the other rows are buttons. The result is written in the email, and drafting a reply still lands in the reply bar.
- **Ask about this email.** That row opens a field on the email. Type the question and press **Send**. The answer stays in the email.

## Installation

If you are on 0.5.6 or newer, the app updates itself. For a fresh install, download **[OkamiUNI.dmg](https://github.com/OkamiOps/okamiuni/releases/latest/download/OkamiUNI.dmg)** and drag **OkamiUNI** to **Applications**.
