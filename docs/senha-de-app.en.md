# App passwords and IMAP compatibility

[Português (Brasil)](senha-de-app.md) · **English**

An app password is a separate credential generated by an email provider for an application. It can usually be revoked without changing the main account password. Whether it is available, and which protocols accept it, depends on the provider and the account administrator's policy.

## Which sign-in method to use

For Google accounts, use OkamiUNI's Google sign-in. The [OAuth guide](oauth-google.en.md) is for configuring a developer build if its client ID is missing.

For the IMAP route, check that the provider allows IMAP/SMTP password authentication. With two-factor authentication, some providers require an app password; others require OAuth and do not accept app passwords for these protocols. A password error can therefore mean an unsupported authentication method, not just a mistyped password.

| Provider | Guidance |
|---|---|
| iCloud | Generate an app-specific password in Apple Account → Sign-In and Security. Two-factor authentication is required. [Apple instructions](https://support.apple.com/en-us/102654). |
| Google over IMAP | Prefer Google sign-in. If using IMAP, check whether your account offers app passwords; availability depends on account and security policy. [Google instructions](https://support.google.com/accounts/answer/185833). |
| Yahoo / Zoho / other providers | Follow the provider's current app-password and IMAP/SMTP instructions. Availability is not guaranteed for every account. |
| Outlook.com / Hotmail / Microsoft 365 | Do not assume an app password will work. Outlook.com requires modern authentication, and Exchange Online has disabled Basic authentication for IMAP. OkamiUNI 0.5.4 does not implement Microsoft OAuth, so these accounts are not supported through its password-based IMAP route. [Outlook.com guidance](https://support.microsoft.com/en-us/office/modern-authentication-methods-now-needed-to-continue-syncing-outlook-email-in-non-microsoft-email-apps-c5d65390-9676-4763-b41f-d7986499a90d), [Exchange Online guidance](https://learn.microsoft.com/en-us/lifecycle/announcements/basic-auth-deprecation-exchange-online). |

## Where OkamiUNI stores it

Account passwords are stored in **Keychain**, not the mail database or a configuration file. Removing an account removes its local credential. To invalidate an app password at the provider, revoke it through that provider's account security settings as well.

Paste the generated password into the IMAP account form. If authentication still fails, check the server, port, TLS setting and provider policy before generating more passwords. This guide is bundled with the app and can be read offline; provider links require an internet connection.
